# Fibonacci Customer Loyalty Reward System

A Data Structures assignment demonstrating the application of the Fibonacci sequence in a customer loyalty reward system.

**Course:** Data Structures

  About:
  
The purpose of this project is to develop a customer loyalty reward system that uses the Fibonacci sequence to calculate reward points based on customer purchase activity, while analyzing different approaches to generate the Fibonacci series.
